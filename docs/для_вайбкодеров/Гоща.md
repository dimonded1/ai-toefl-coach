# Гоща: frontend, UI, dashboard

## Твоя зона ответственности

Ты отвечаешь за то, чтобы интерфейс был понятным, красивым, простым и не перегруженным.

## Главная задача

Пересобрать dashboard так, чтобы пользователь сразу видел:

1. Где он сейчас.
2. До какой цели идёт.
3. Что делать сегодня.
4. Почему именно это.

## Основные файлы

- `frontend/index.html`
- `frontend/src/styles/main.css`
- `frontend/src/scripts/app.js`
- `frontend/src/scripts/aiPlan.js`, только если меняется UI AI-блока

## Что можно менять самому

- Layout.
- CSS.
- Карточки.
- Навигацию.
- UI copy.
- Empty/loading/error states.
- Mobile layout.
- Focus states.

## Что согласовывать

- Изменение структуры profile/scoring.
- Изменение backend endpoint.
- Изменение AI payload.

## Главные проблемы frontend сейчас

- Dashboard перегружен равнозначными карточками.
- Нет одного главного next action.
- Sidebar слишком дробный.
- Много emoji.
- Много inline styles в JS.
- Не хватает accessibility states.

## Твои задачи по спринтам

### Sprint 4
