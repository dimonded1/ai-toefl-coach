## Главная задача

Сделать backend не просто прокси, а нормальным AI/API слоем:

- понятный naming;
- validation;
- timeout;
- rate limit;
- provider abstraction;
- нормальные ошибки;
- защита ключа Groq.

## Основные файлы

- `backend/server.js`
- `backend/routes/ai.js`
- `backend/routes/gemini.js`, только как legacy alias
- будущие `backend/services/*`
- будущие `backend/prompts/*`
- будущие `backend/validators/*`
- будущие `backend/config/*`

- Rate limiting.

## Что согласовывать

- Изменение URL endpoint для frontend.
- Изменение формата JSON-ответа.
- Добавление базы.
- Добавление auth.

## Главные проблемы backend сейчас

- Основной route уже `/api/ai`, Groq используется как активный провайдер.
- Есть базовый rate limit, validation, timeout и backend-проверка JSON.
- Нет полноценной auth/session модели для публичного SaaS.
- Нет retry/backoff и отдельного provider service слоя.
