# Олег: backend, AI API, безопасность

## Твоя зона ответственности

Ты отвечаешь за backend, AI-интеграцию, безопасность API и устойчивость запросов к Groq.

## Главная задача

Сделать backend не просто прокси, а нормальным AI/API слоем:

- понятный naming;
- validation;
- timeout;
- rate limit;
- provider abstraction;
- нормальные ошибки;
- защита ключа Groq.

## Основные файлы

- `backend/server.js`
- `backend/routes/gemini.js`
- будущие `backend/routes/ai.js`
- будущие `backend/services/*`
- будущие `backend/prompts/*`
- будущие `backend/validators/*`
- будущие `backend/config/*`

## Что можно менять самому

- Внутреннюю структуру backend.
- AI route.
- Prompt builders.
- Error handling.
- Timeout.
- Validation.
- Rate limiting.

## Что согласовывать

- Изменение URL endpoint для frontend.
- Изменение формата JSON-ответа.
- Добавление базы.
- Добавление auth.

## Главные проблемы backend сейчас

- Файл называется `gemini.js`, но используется Groq.
- Нет rate limit.
- Нет validation схемы.
- Нет timeout/retry/backoff.
- Нет auth/session.
- AI JSON валидируется на клиенте, а не на backend.
