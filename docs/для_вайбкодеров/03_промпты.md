```text

Моя ветка: <Gosha|Andrew|Oleg|Dima>. Не работай в main для обычной задачи.
Цель задачи: <цель>.
Файлы, которые можно менять: <пути>.
Файлы, которые нельзя менять без согласования: <пути>.
Сначала кратко проверь текущую структуру, затем внеси изменения, потом проверь результат.
Не ломай существующее поведение. Если есть риск, зафиксируй его.
```

## Промпт для code review

```text
Проведи code review изменений.
Сначала найди баги, регрессии, риски и недостающие проверки.
Потом кратко дай summary.
Особенно проверь: не сломан ли запуск, не изменился ли API contract, нет ли смешения зон ответственности, нет ли секретов в коде.
```
