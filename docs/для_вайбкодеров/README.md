# Для вайбкодеров: командная папка AI TOEFL Coach

Эта папка нужна, чтобы команда из 4 человек не работала хаотично в одних и тех же файлах.

## Состав команды

- Дима: продукт, архитектура, интеграция, финальное ревью.
- Гоща: frontend, UI, dashboard, дизайн-система.
- Олег: backend, AI API, безопасность, Groq/provider слой.
- Андрей: scoring, данные, аналитика, модель прогресса.

## Как пользоваться папкой

1. Сначала открыть `00_установка.md` и поднять проект.
2. Потом открыть `01_зоны_ответственности.md` и понять границы своей работы.
3. Потом открыть личный файл: `Дима.md`, `Гоща.md`, `Олег.md`, `Андрей.md`.
4. На спринт смотреть в `02_спринты.md`.
5. Для постановки задач AI использовать `03_промпты.md`.

## Главное правило

Каждый делает свою зону, но не ломает общий продуктовый контур:

цель пользователя → диагностика → следующий шаг → практика → обратная связь → обновлённый прогноз.
