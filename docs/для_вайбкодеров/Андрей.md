# Андрей: scoring, данные, аналитика

## Твоя зона ответственности

Ты отвечаешь за то, чтобы прогноз TOEFL, progress, weak zones и analytics были честными и полезными.

## Главная задача

Сделать расчёты не игрушечными, а объяснимыми:

- skill score;
- progress;
- proficiency;
- confidence;
- difficulty weights;
- recency;
- sample size.

## Основные файлы

- `frontend/src/scripts/profile.js`
- `frontend/src/scripts/data.js`
- будущий `frontend/src/scripts/scoring.js`
- будущий `frontend/src/scripts/analyticsModel.js`

## Что можно менять самому

- Scoring functions.
- Confidence logic.
- Mistake logic.
- Progress/proficiency split.
- Data model для attempts/answers.

## Что согласовывать

- Изменение UI dashboard.
- Изменение backend payload.
- Переход на backend DB.
- Изменение основной TOEFL-шкалы.

## Главные проблемы scoring сейчас

- Section score считается как `accuracy * 30`.
- Нет веса difficulty.
- Нет веса свежести.
- Нет confidence.
- Speaking оценивается regex-критериями.
- Progress и proficiency смешаны.
- В данных смешиваются шкалы `0-120`, `0-30` и новая `1-6`.
