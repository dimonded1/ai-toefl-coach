# 00. Установка и запуск проекта

## Что нужно установить

- Git.
- Node.js 18+.
- Docker Desktop, если запускаете через Docker.
- Groq API key.
- VS Code или другой редактор.

## Быстрый запуск через Docker

```bash
cd ai-toefl-coach
cp backend/.env.example backend/.env
```

В `backend/.env` указать:

```env
GROQ_API_KEY=your_actual_key_here
PORT=3001
```

Запуск:

```bash
docker-compose up --build
```

Открыть:

```text
http://localhost:8080
```

Проверить backend:

```text
http://localhost:3001/health
```

## Локальный запуск без Docker

Backend:

```bash
cd backend
npm install
npm run dev
```

Frontend:

```bash
cd frontend
npx serve .
```

Открыть:

```text
http://localhost:3000
```

Важно: при `localhost:3000` frontend ходит к backend напрямую на `http://localhost:3001/api/gemini`, поэтому backend должен быть запущен отдельно.

## Проверка после запуска

- Приложение открывается.
- Goal setup сохраняет профиль.
- Dashboard показывает target/current/gap/days.
- Practice-секции открываются.
- Mini test запускается.
- AI Study Plan либо получает ответ от Groq, либо показывает local fallback.
- В консоли браузера нет новых ошибок.
